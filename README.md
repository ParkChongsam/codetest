# 제품 가치 추천 사이트

제품을 입력하면 새로운 관점에서 가치있는 아이디어 상품을 추천해주는 웹 애플리케이션입니다.

## 기능

- 제품명을 입력하면 다양한 관점에서 새로운 가치를 제안
- 6가지 카테고리로 분류된 창의적인 추천:
  - 🌱 지속가능성: 환경을 생각하는 가치
  - ♿ 접근성: 모든 사람을 위한 디자인
  - 🤖 스마트화: 기술을 활용한 혁신
  - 🔧 다기능성: 효율성 극대화
  - 💝 감성가치: 특별한 경험 제공
  - 💪 건강/웰빙: 건강한 생활 지원

## 기술 스택

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **스타일**: 반응형 디자인, 그라데이션 UI

## 설치 및 실행

1. 의존성 설치:
```bash
npm install
```

2. 서버 실행:
```bash
npm start
```

3. 브라우저에서 접속:
```
http://localhost:3000
```

## 사용 방법

1. 메인 페이지에서 제품명을 입력하거나 예시 버튼 클릭
2. "추천받기" 버튼을 클릭
3. AI가 생성한 창의적인 제품 가치 추천 확인
4. 각 추천은 카테고리, 설명, 가치 포인트를 포함

## 예시

- 우산 → 친환경 소재 우산, 스마트 날씨 알림 우산
- 텀블러 → 온도 유지 기술, 건강 모니터링 기능
- 책상 → 공간 절약형 다기능 책상, 인체공학적 디자인
