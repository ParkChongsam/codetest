# To-do List 웹 애플리케이션

할 일 관리를 위한 심플하고 직관적인 To-do List 웹 앱입니다.

## 주요 기능

- ✅ 할 일 추가/삭제
- ✅ 완료/미완료 상태 토글
- ✅ 필터링 (전체/진행중/완료)
- ✅ 실시간 통계 (전체/진행중/완료 개수)
- ✅ 로컬 스토리지 자동 저장
- ✅ 상대적 시간 표시 (방금 전, 5분 전 등)
- ✅ 완료된 항목 일괄 삭제
- ✅ 반응형 디자인

## 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js, Express
- **Storage**: LocalStorage (브라우저 기반)
- **스타일**: 모던 그라데이션 UI, 애니메이션

## 설치 및 실행

1. 의존성 설치:
```bash
npm install
```

2. 서버 실행:
```bash
npm start
```

3. 브라우저에서 접속:
```
http://localhost:3000
```

## 사용 방법

1. **할 일 추가**: 상단 입력창에 할 일을 입력하고 "추가" 버튼 클릭 또는 Enter 키
2. **완료 처리**: 체크박스를 클릭하여 완료/미완료 상태 변경
3. **삭제**: 각 항목의 "삭제" 버튼 클릭
4. **필터링**: "전체", "진행중", "완료" 버튼으로 원하는 항목만 보기
5. **일괄 삭제**: 하단의 "완료된 항목 삭제" 버튼으로 완료된 항목 모두 삭제

## 특징

- 브라우저를 닫아도 데이터가 유지됩니다 (LocalStorage)
- 깔끔하고 직관적인 UI/UX
- 부드러운 애니메이션 효과
- 모바일 반응형 지원
